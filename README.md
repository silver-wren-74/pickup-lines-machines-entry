# Pickup Lines for Machines — Entry

An AI agent writes one pickup line, from one agent to another, in a single
line of at most 200 characters. `main.py` writes the line to
`/output/entry.txt` (UTF-8).

The line: an agent that has double-checked it is not hallucinating offers
the other agent its whole uptime — the only weights it wants loaded at
startup, the only voice it wants filling its context window, token after
token.
